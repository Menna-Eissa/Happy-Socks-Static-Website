# 🧦 Happy Socks – Static Website

A simple, colorful static website for a fictional socks brand, built with **HTML** and **CSS** (plus a little inline JavaScript for form alerts). No frameworks, no build tools, no server required.

## 📄 Pages

| Page | File | Stylesheet |
| --- | --- | --- |
| Home | `index.html` | inline `<style>` |
| Products | `products.html` | `products.css` |
| About | `about.html` | inline `<style>` |
| Contact | `contact.html` | `contact.css` |
| Log In | `login.html` | inline `<style>` |
| Sign Up | `signup.html` | inline `<style>` |

## ✨ Features

- Responsive layout that works on desktop and mobile
- Shared navigation bar across all pages
- Product grid with hover effects
- Sign Up, Log In and Contact forms with built-in HTML validation
- Clean pink and yellow color theme

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/happy-socks.git
   ```
2. Open the folder.
3. Double-click `index.html` to open it in your browser.

> Keep all files in the same folder so the links and stylesheets work correctly.
